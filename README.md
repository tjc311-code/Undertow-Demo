# Undertow Demo

A surfing demo for friends. Windows 64-bit; controller recommended.

## [Download the Windows demo](https://github.com/tjc311-code/Undertow-Demo/releases/download/windows-demo-2026-11-12/Undertow-Demo-Windows.zip)

1. Download the ZIP (about 85 MB).
2. Extract the entire ZIP into a folder.
3. Open **Undertow.exe** in that folder. Keep all the included files together.

The controller guide appears at startup and is available from the pause menu. Choose your board, character and day/night map, then play the five-minute Demo.

This playtest includes a landing-balance experiment: bigger aerial tricks require a brief right-stick correction, while the left stick keeps steering. Water poses use left-stick countersteering. Falling loses pending points.
